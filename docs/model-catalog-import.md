# 模型目录批量导入

在“模型目录 → 企业模型目录”点击“从供应商导入”，选择已启用的连接并读取模型列表。勾选后批量导入；已有的上游模型标识会跳过。导入记录默认停用；可勾选“导入时启用所选模型”。图片、视频等非对话模型可在目录中处于启用状态；各类型使用各自的调用入口。旧接口参数 `activateSupportedChat` 仍保持原有行为，供已有客户端兼容使用。

供应商协议支持 OpenAI 兼容、DeepSeek、阿里云百炼、Kimi、Ollama、硅基流动、Claude 和 Gemini。列表读取分别使用其模型列表接口；Ollama 读取本机已安装模型。通用兼容接口通常只返回模型 ID，因此无法确定类型的条目记为“待确认”。百炼优先使用 `/api/v1/models` 的模态和能力元数据；该接口返回 404 时尝试兼容 `/models`。只有两个接口都返回 404，才需要在供应商连接中填写独立的“模型目录地址”，例如与 API Key 同地域的业务空间完整模型列表地址 `https://{业务空间ID}.cn-beijing.maas.aliyuncs.com/api/v1/models`。对话 API 基础地址可以保留原值。

模型目录可登记对话、图片、视频、音频、向量及重排模型。对话、图片和视频分别使用聊天补全、图片生成、异步视频生成入口；图片生成支持 OpenAI 兼容与百炼连接，视频生成目前支持百炼连接。Claude、Gemini 原生协议以及音频、向量、重排调用尚未接入网关，这些模型仍可在目录收录。策略中的可选模型和路由会过滤未受支持的类型及协议。具体调用方式见[图片与视频模型网关](model-media-gateway.md)。

列表接口最多返回 500 个模型；导入前服务端会重新读取并核对所选 ID。批量写入在一个数据库事务内完成，记录审计事件，且不会保存供应商密钥到目录项。

已导入模型可在“企业模型目录”按类型和目录状态筛选，跨页勾选后批量启用或停用。也可选中当前筛选结果，每次最多处理 500 个。批量状态修改只作用于当前企业；如果所选 ID 中有不存在或不属于当前企业的模型，整批不修改。已是目标状态的模型不会重复计入改动数量，操作会记录审计事件。启用目录项并不保证供应商支持该具体模型的协议，调用失败时会透传供应商错误。
