# 模型目录批量导入

在“模型目录 → 企业模型目录”点击“从供应商导入”，选择已启用的连接并读取模型列表。勾选后批量导入；已有的上游模型标识会跳过。导入记录默认停用；可勾选“导入时启用所有选中的模型”。图片、视频等非对话模型可在目录中处于启用状态，但当前对话网关不会调用它们。旧接口参数 `activateSupportedChat` 仍保持原有行为，供已有客户端兼容使用。

供应商协议支持 OpenAI 兼容、DeepSeek、阿里云百炼、Kimi、Ollama、硅基流动、Claude 和 Gemini。列表读取分别使用其模型列表接口；Ollama 读取本机已安装模型。通用兼容接口通常只返回模型 ID，因此无法确定类型的条目记为“待确认”。百炼优先使用 `/api/v1/models` 的模态和能力元数据；该接口返回 404 时尝试兼容 `/models`。只有两个接口都返回 404，才需要在供应商连接中填写独立的“模型目录地址”，例如与 API Key 同地域的业务空间完整模型列表地址 `https://{业务空间ID}.cn-beijing.maas.aliyuncs.com/api/v1/models`。对话 API 基础地址可以保留原值。

模型目录可登记对话、图片、视频、音频、向量及重排模型。当前对话网关仅路由对话模型，且 Claude、Gemini 原生协议尚未接入该网关；这些模型仍可在目录收录。策略中的可选模型和对话路由均会过滤未受支持的类型及协议。

列表接口最多返回 500 个模型；导入前服务端会重新读取并核对所选 ID。批量写入在一个数据库事务内完成，记录审计事件，且不会保存供应商密钥到目录项。
