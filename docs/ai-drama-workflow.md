# 漫剧解析、资产与视觉风格

## 当前解析流程

新建和重新解析使用第三版事实约束工作流。上传后的项目概览读取原文前最多10万字，仅供阅读和人工整理。人工修改主角、故事类型、故事梗概、背景和设定不会成为后续改编的事实依据；不支持通过修改概览剧情要求AI改编原文。画面风格、比例属于独立创作配置。

剧本批次最多10万字，自动范围优先在上限以内最接近的下一章或下一集开头收尾；没有标题时再寻找段落边界。上传原文保持不变，批次只保存起止字符位置。阅读单元约1000字符，每次理解任务包含最多5000字符的原文，阅读单元不直接等于最终集数。

当前执行顺序为：分组美术提取与剧情整理 → 本批上下文 → 整批分集规划 → 独立批次命名 → 逐集导演写作 → 累计审校与局部修正 → 正式保存。独立美术和剧情任务最初串行；单次请求超过45秒后，后续独立任务的并行上限可升至2，发生自动重试后降回1。逐集生成和审校顺序执行。单次文本模型调用上限10分钟，整批任务上限8小时。

整批规划必须按连续原文单元覆盖全部范围，不得遗漏、重叠、调序或引用后集事实；每集最多分配16000字符原文。梗概与结尾依据由实际引用事实组成，不沿用模型自由补写的跨集信息。原文明确的第N集边界不能被规划跨越。

本批上下文独立于最初概览，范围是当前批次，起点前最多补读6000字符用于承接，更早未读内容不作推断。单集导演只接收本集原文、范围内证据、已确认前情、画面格式及统一资产名称，不接收全批资产描述或整批摘要，避免后文信息倒灌。下一集以前一集梗概衔接。

## 编号引用与单元检查点（迁移49）

程序先在每个单元内生成句段编号，例如U3S2。剧情整理AI返回事实和sourceIds，程序检查编号属于当前单元后，直接从上传原文回填quote、startOffset和endOffset。模型自行返回的引文、偏移和references不作为位置依据。一个事实可以分别引用多处原文，每处保存在references数组中，不把非连续文字拼成一段。旧的quote/startOffset/endOffset字段兼容表示首处依据。

兼容旧式引文时，定位可以统一CRLF/LF及行首空格、制表符、全角缩进，并通过字符映射回到原始上传文本；不修改上传原文，不删除否定词、标点或正文内部空格。数字编号的纯数字字符串可安全转换，浮点、负数、空值或任意文本不接受。结构、编号、长度、引用不存在、跨单元和引文内容变化分别报错，不再统一提示为“补写事实”。

请求仍按组进行，但每个通过的单元单独保存为evidence阶段检查点。组内一部分通过、一部分失败时，先持久化通过部分，只将失败或遗漏的单元发给模型重试。继续解析复用有效单元，失败组不再导致已完成单元重复生成。每次执行最多两次模型请求，不无限循环。界面显示证据单元完成数，组级失败行保留“从此处继续解析”。

检查点输入指纹绑定运行标识、模型、工作流版本与实际输入。原文范围变化或输入改变时不能复用旧结果。步骤结果和运行上下文以结构化文本保存，属于可恢复检查点；正式角色、场景、道具、剧集及关联使用明确业务表字段。

这些规则验证出处、范围和位置；语义是否忠实仍由AI审校，不能作为事实正确性的数学证明。

## 审校、续跑与日志

审校问题保存于明确字段表drama_review_issues，包含事实、衔接、关键因果、表达四类问题、阻断/建议级别、原文和剧本依据、位置及open/resolved状态。表达建议不阻断。每次修正只替换唯一可定位的局部片段，保留无关正文；每轮审校同时复核历史已解决问题，避免修正回归。每次执行最多两次局部修正，继续解析沿用累计约束。

重新解析创建新运行标识并清除本次阶段检查点和事件。现存正式结果在新结果全部通过后才替换，失败不先清空上次成功正文。从此处继续解析只用于失败且范围未变化的任务，沿用原模型及创作格式快照。旧第二版任务继续时升级为第三版，一版旧流程仍保留兼容路径。

模型输出采用流式接收，不展示模型推理字段。正文未校验前以待校验预览展示。真实的开始、接收、检查点、重试、完成、修正和调度事件写入事件表，通过SSE推送，断线后按事件序号续传。请求、原始响应（含原始SSE）、耗时、用量和错误保存到原有模型调用日志，查看权限由网关日志接口控制。

## 资产、批次与制作入口

资产身份由项目资产主键确定，每集与同一资产只关联一次；状态说明不参与身份判定。移除本集关联不删除资产目录记录。资产目录新增、修改与剧本关联均以真实主键为准，防止出现名称相同但互不关联的影子资产。

批次编号固定递增，名称可双击编辑，Enter或失焦保存，Escape取消。整批规划后有独立AI命名步骤，手动命名后跳过自动起名，运行中修改也不会被覆盖。来源关系保存首次提取批次主键，应用关系根据实际剧集关联推导。筛选项实时读取批次名称，改名后不复制旧名称。

资产页将角色、场景、道具切换、来源批次筛选、应用批次筛选、图片模型设置和项目画布入口放在同一工具栏。来源与应用筛选组合取交集，并随URL保留刷新状态。卡片不再展示来源/应用标签。尚未生成图片时卡片内部显示资产名称，卡片下为生成按钮；已生成后下方显示名称文本。悬浮预览与聚焦当前资产的画布入口继续保留。

剧本分集以正式可拍摄剧本为准，视频分集使用同一drama_script_episodes.id作为制作入口，不复制正文和资产。正式剧本出现后立即显示视频卡片；没有正文的旧概览分集规划不进入制作列表。制作页左侧展示本集真实资产，右侧显示待拆分状态。URL保留当前菜单、批次或剧集。当前已接入真实AI文字分镜（见下节），片段视频生成及合成尚未接入，不显示虚构媒体成果。

## 统一视觉风格（迁移49）

风格目录drama_visual_styles使用明确字段保存风格ID、名称、分类、预览图、排序、启用状态、生图模板和生视频模板。历史名称回填为对应风格ID，无法匹配的历史自定义名称保留为独立风格记录。项目和形象均引用style_id，形象可独立修改自己的选择。

首页、项目概览、画布生成面板及形象编辑使用同一个带图片预览和分类的风格选择器。普通风格接口只返回id、name、category、previewUrl、previewX和previewY。新请求提交风格ID，服务端校验启用状态并使用服务端名称；旧名称输入保留兼容。生图最终提示词由服务端结合对象类型、用户描述及风格模板组装。

生成任务不再通过普通业务响应返回最终prompt。供应商可能回显请求的错误也只返回分类后的简短消息，具体错误保留在服务端记录中。完整提示词快照仍保存在服务端任务和受权限控制的模型调用日志中。生视频模板已经保存供后续制作接入，当前尚未调用视频模型。

## 图片与自由画布

图片生成使用当前用户漫剧设置中的图片模型，经过原有模型网关启用状态、权限和限流检查。任务单次模型调用上限10分钟，总任务上限12分钟。图片失败保留上次成功封面，生成中的形象内容禁止编辑，但仍可拖动布局。服务重启把未完成任务标记为中断，不自动重复付费。

自由画布使用React Flow，支持拖动、平移、缩放、缩略图、适应画布、整理布局、预览和编辑。项目共用一张画布，卡片悬浮入口定位当前资产；视口和选中形象刷新恢复。布局自动保存并使用版本检查，多页面冲突需要重新加载，网络失败可重试。

drama_asset_forms通过asset_id关联真实资产，parent_id只指向同一资产的来源形象。添加变异形象不会新建重复角色或改变剧集关联。默认形象第一次进入画廊时初始化，以后不覆盖人工编辑。派生生成使用父形象当前成功的图片作为参考，并保存具体reference_id；父图后续重新生成不会改变已建立的任务。参考图和尺寸是否受支持由具体模型决定。

图片元数据与任务保存在drama_image_jobs，文件独立保存于DRAMA_MEDIA_DIRECTORY（默认./data/drama-media，已加入Git忽略）。部署应持久化此目录并与数据库一起备份。图片读取始终校验项目所有者，下载模型返回的URL复用网关DNS与私网检查，不跟随跳转。支持PNG、JPEG、WebP、GIF，单张最多20MB。

## 验证与部署

新增接口及响应契约见api/openapi.yaml。启动服务可自动迁移，也可显式执行DATABASE_URL=... go run ./cmd/migrate。修改后使用新代码重启服务，并先确认没有正在执行的模型任务。

常规验证包含Go测试、前端构建、PostgreSQL集成测试和新旧基线对比。真实模型联调必须显式设置HARNESS_TEST_DRAMA_MODEL_PROJECT_ID，只创建并清理临时项目，不修改参考项目和用户原有批次。

## 单集AI分镜（迁移50）

视频分集使用原有正式剧本主键，当前已接通文字分镜制作。输入只包括本集剧本、实际关联资产的可选形象、画幅和前片段承接；人工概览和小说其他批次不作为事实依据。项目文字模型由当前用户的漫剧设置读取，新运行冻结模型和来源快照，续跑保留原模型。

执行为整集导演规划 → 逐片段分镜编写 → 程序检查 → AI针对性审阅 → 片段保存。按场次、动作和情绪切分片段，片段内包含具体镜头。8～15秒是规划目标，并非供应商能力保证。实际视频模型尚未接入，因此当前时长统一标为待执行能力校验；不自动生成图片或视频。

程序给非空剧本行生成L编号，规划必须连续、不重叠地覆盖全剧本。镜头引用这些真实行，页面按快照回填依据。检查画面、景别、运镜、时长、台词粗估时长下界、真实形象ID及台词来源，典型说话者行必须完整保留台词；AI检查重要事件、因果、空间与动作连续性，合理构图与表演不按逐字匹配阻断。每片段最多自动修正一次，失败后停止，已完成片段立即可读。继续只编写尚未通过的片段，不重新调用已保存片段。

数据分别保存于drama_storyboard_runs、segments、shots、shot_sources、utterances、bindings、events明确字段表。资产绑定引用真实form_id和采用的image_id，重生资产图不替换已有采用图片。待素材引用不假称图片已就绪；人工保存新版本时可补充当前已成功的图片。普通接口只返回分镜内容，不返回服务器风格模板。

制作台支持片段切换、剧本依据、镜头和片段增删排序、画面/台词/声音类型/时长编辑、真实形象选择、确认和只读历史。每次人工保存创建独立版本；旧版本不被修改。最新失败尝试和旧成功版均保留。当前片段与历史版本写入URL，刷新可恢复；运行进度每两秒读取，流式接收的实际字数和检查结果记录为持久事件，不展示模型思考。完整模型请求、原始响应和错误仍经模型网关记录。

剧本或资产关联变更时提示来源失效，禁止续跑、编辑和确认旧来源；可重新拆分建立新版本。剧本重新拆集删除旧剧集时分镜保留来源主键和快照，关联剧本置空。服务重启将未完成的分镜标记为可续跑的中断任务，不自动重复调用模型。后续视频生成与合成仍需独立接入。
